# 02. Connected Intelligence Architecture & System Topology

## 1. The Connected Intelligence Triad

Catalyst OS operates as a unified career intelligence system powered by three foundational connections:

```mermaid
graph TD
    subgraph CONNECTION A [Phase 5C.1: Gap ➔ Blueprint]
        G[Calculated Skill Deficits in /analytics & /skills] -->|findBlueprintRecommendation| B[Actionable STAR Blueprints in /project-generator]

    subgraph CONNECTION B [Phase 5C.2: Cause ➔ Effect Readiness Feedback]

    end

    subgraph CONNECTION C [Phase 5C.3: Pipeline ➔ Contextual Interview Prep]
        P[Job Application in Interview Stage] -->|resolveCompanyContext| I[Prioritized Technical Questions & Focus Topics in /interview-prep]
    end

    CONNECTION A --> CONNECTION B
    CONNECTION B --> CONNECTION C
```

---

## 2. Integrated System Flow

1. **Gap Resolution Loop**: Competency deficits directly suggest engineering architectures with pre-filled milestones.
2. **Evidence Crediting Loop**: Completing projects, algorithmic challenges, or credential verifications updates unified readiness telemetry and provides real-time causal explanations.
3. **Pipeline Readiness Loop**: Active interview rounds dynamically prioritize company-targeted questions, focus topics, and empirical benchmark artifacts.
